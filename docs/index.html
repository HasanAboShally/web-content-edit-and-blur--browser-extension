Why redaction exists

Blurring hides it.
Redaction removes it.

A blur keeps every pixel it started with — it just spreads them out. Given the original layout and a known blur radius, that is often enough to reconstruct what was underneath. Redaction has nothing left to reconstruct.

The toolkit

Six tools. One click each.

Edit

Click any text and rewrite it. Alt+R replaces every occurrence at once. Double-click an image to swap it for a local file.

Blur

Click an element or drag an Area, then choose Soft or Strong directly. Select an existing blur to edit or remove it.

Redact Advanced

A solid, irreversible block. Flattens text, images, video and canvas alike — nothing survives to be recovered.

Hide & Area

Remove an element entirely, or target a precise rectangular area with Blur or Redact — no element required.

Annotate

Arrows, circles, boxes, text notes, freehand Pen and a highlighter that keeps the text underneath readable. Advanced adds numbered Steps.

Screenshot

Capture what's on screen with every edit applied. The toolbar and overlays hide themselves first, so they never end up in the shot.

Essentials

What the toolbar opens with

  • Edit and Annotate content
  • Blur and Hide for privacy, with Element or Area targeting
  • Annotate — arrows, circles, boxes, Pen, highlighter and text
  • Undo, Redo, Screenshot and Reset

Everything needed for the everyday workflow.

Advanced

One click away

Everything above, plus

  • Redact — irreversible, unlike blur
  • Scope — apply a rule to one page or every page on the domain
  • Rules panel — review, locate, re-scope or delete any rule
  • Export / import your rules as JSON
  • Annotate: numbered Steps for walkthroughs

Your choice is remembered.

Privacy

It never phones home.
Not even once.

The extension makes no external requests of any kind. No telemetry, no analytics, no account. Everything you edit stays in your browser's local storage.

Works offline

No network calls, so nothing to intercept and nothing to leak.

Local storage only

Your rules live in chrome.storage.local. Never synced, never uploaded.

Minimal footprint

A 24-line script runs on pages, only to track the last right-clicked element. The editor loads on demand.

Auditable
