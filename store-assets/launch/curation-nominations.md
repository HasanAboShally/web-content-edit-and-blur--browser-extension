## Chrome Featured badge nomination

**Extension:** Content Edit & Blur

**Listing:** https://chrome.google.com/webstore/detail/content-edit-blur/adgnogkndmhcblbonkhgfbbngeghpboh

Content Edit & Blur is a free browser extension for preparing webpages for mockups, screenshots, bug reports and screen shares. It lets people edit text and images, blur or hide content, apply opaque redaction, annotate the page and capture the result in one focused workflow.

The core experience requires no credentials or payment. It uses Manifest V3, contains no remote code, performs no analytics or external requests, and stores eligible rules only in local browser storage. The complete source and test suite are public under the MIT license.

The extension has been maintained since 2020. The Chrome listing currently shows 6,000 users and a 4.5/5 rating from 20 ratings. The unreleased 2.5.0 update adds a neutral, one-time review request after the third successful screenshot, practical workflow guides and refreshed store media. Its screenshot counter and permanent dismissal state remain in local extension storage. The listing includes five current 1280×800 screenshots, and new promotional tiles and a captioned demo are ready.

The all-sites permission restores user-created local rules after navigation. Only a small right-click target tracker runs at page start; the full editing engine loads on activation or when saved rules need restoration.

## Firefox Recommended extension nomination

**To:** amo-featured@mozilla.org

**Subject:** Recommended extension nomination — Content Edit & Blur

Hello Mozilla Add-ons team,

I would like to nominate Content Edit & Blur for consideration in the Recommended Extensions program:

https://addons.mozilla.org/en-US/firefox/addon/content-edit-blur/

The extension provides one focused visual communication workflow: edit webpage content, protect sensitive details, annotate the result and capture a clean screenshot. It is useful for product mockups, documentation, bug reports and screen shares.

It has been maintained since 2020 and supports Firefox, Chrome and Edge from a shared, build-free JavaScript codebase. It has no account, analytics, remote code or external requests. Remembered changes stay in local browser storage, and annotations remain session-only unless the user explicitly opts in. The source, architecture notes and browser test suite are public under the MIT license.

Recent work rebuilt the toolbar around a clearer always-light interface, separated blur from opaque screenshot redaction, made privacy effects and annotations directly editable, and added explicit local-persistence language. Redaction remains undoable on the live page; the final screenshot contains replacement pixels instead of a blurred source. Firefox packages declare no data collection and are tested through a real package-install smoke test before release.

The all-sites permission restores user-created local rules after navigation. Only a small right-click target tracker runs at page start; the full editing engine loads on activation or when saved rules need restoration. The project repository is MIT licensed; the Firefox listing license metadata should be aligned before nomination.
