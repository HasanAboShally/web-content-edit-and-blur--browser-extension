# Content Edit & Blur press kit

## One-line description

Content Edit & Blur is a free, open-source browser extension for editing, blurring, redacting and annotating webpages before screenshots, mockups and screen shares.

## Who it helps

- Product managers creating realistic concepts from an existing interface
- Designers and writers testing copy in context
- QA and support teams annotating visual bug reports
- Educators and technical writers producing walkthroughs
- Anyone removing sensitive details before a screenshot or screen share

## What makes it different

- The work happens directly on a supported webpage rather than in an uploaded image editor.
- Blur and opaque redaction are separate tools with clear privacy guidance.
- Text edits, image replacement, privacy effects, annotations and capture live in one focused workflow.
- There is no account, analytics, telemetry, backend, cloud processing or remote code. The extension does not transmit page content; the underlying website remains connected and may observe DOM changes.
- The same open-source extension supports Chrome, Firefox and Edge.
