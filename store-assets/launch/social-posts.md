## LinkedIn

A screenshot is often where product work leaves the room.

That is exactly when customer names, account values or internal URLs are easiest to expose.

I maintain Content Edit & Blur, a free browser extension that lets you prepare the real webpage before sharing it:

- edit copy for a realistic mockup
- blur visual distractions
- redact sensitive pixels
- annotate a bug or walkthrough
- capture a clean screenshot

The extension has no account, analytics, backend or cloud processing and does not transmit page content. The underlying website remains connected, and the source code is public.

The project has been maintained since 2020 and is listed for desktop Chrome, Firefox and Edge.

Try the live demo without installing anything:
https://hasanaboshally.github.io/web-content-edit-and-blur--browser-extension/#demo

## Indie Hackers

### Title

What six years of maintaining a no-account browser extension taught me about distribution

### Draft

Content Edit & Blur began as a small utility for changing webpage copy and blurring details before screenshots. It is now listed for desktop Chrome, Firefox and Edge. Public figures checked September 9, 2026 show 6,000 Chrome users, 3,712 Edge users and 86 Firefox average daily users; the populations may overlap.

The product has no signup or analytics, which is part of its appeal but also removes the usual growth dashboards. The useful signals have come from store searches, reviews, issues and actual workflows people describe.

The strongest lesson so far: users search for a job, not a feature bundle. “Blur webpage,” “redact screenshot,” “product mockup,” and “annotate bug report” describe four different moments even when one tool serves all of them.

I have started treating each moment as its own useful explanation, while keeping one focused extension:

- privacy-safe screenshots
- screen-share preparation
- realistic product mockups
- visual bug reports

The extension remains free, open source and local-only. I would value feedback from other extension maintainers: what improved store conversion without damaging user trust?
